# Artefatos de distribuição

O repositório principal contém o runtime e os dados necessários para a consulta publicada.

Os seguintes produtos devem ser tratados como artefatos gerados e, quando desejado, anexados a uma GitHub Release

- variantes `JOAJU_MS_SINGLEFILE_*.html`
- exportações integrais KML
- exportações integrais KMZ
- pacotes GeoJSON ou GeoPackage
- resultados intermediários de materialização

Isso reduz duplicação e evita manter no histórico Git grandes arquivos que podem ser reconstruídos.
