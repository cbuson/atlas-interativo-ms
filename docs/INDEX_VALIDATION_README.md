# INDEX VALIDATION 1.0

Este arquivo documenta a regra de interpretação dos índices exibidos pelo Atlas.

Os índices são produtos analíticos do projeto. Devem ser lidos junto com a qualidade, atualidade, completude e proveniência das camadas de entrada. Um valor alto ou baixo não equivale a aprovação, certificação, prioridade administrativa ou aptidão turística automática.

A reprodução de qualquer resultado deve registrar versão do Atlas, data, camadas utilizadas, parâmetros e fontes disponíveis no momento do cálculo.
