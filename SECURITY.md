# Segurança e dados sensíveis

Não publique chaves de API, credenciais, tokens ou arquivos `.env` neste repositório.

Falhas que possam expor coordenadas arqueológicas precisas, dados comunitários
sensíveis ou credenciais devem ser comunicadas diretamente aos autores, evitando
abrir uma Issue pública com os detalhes completos.

O modo público permanece ativado por padrão e generaliza coordenadas arqueológicas.
A disponibilidade pública de dados administrativos não autoriza exploração turística,
reprodução de conhecimento tradicional nem divulgação de locais comunitários sensíveis.
